# 企画書: 政治の動きタイムライン (試験公開版)

> 1〜6 は README・STATUS の内容と依頼 (「試験的に公開したい。DB は今ある分だけでよく、収集機能もいらない」) から下書きしたもの。
> 内容が違えば書き換えてください。7〜9 は AI の案。

## 1. ひとことで

政府と各党が **これまで何をしてきたか・今何をしているか・これから何をしようとしているか** を、
一次資料の原文と出典 URL つきで、スマホでさっと見比べられるページ。

## 2. 誰が使うか

ニュースで見た政策の話題について、「政府は実際に何を決めたのか」「各党はどう言っているのか」を
報道の要約ではなく元の資料で確かめたい人 (学生・一般の有権者)。

## 3. いちばん大事な機能

- 収集済みの資料から取り出した出来事 (政府・各党の実績・進行中・予定) を、時期の順に一覧で見られる
- 主体 (政府・各党) と分野で絞り込める
- 出来事を開くと、根拠になった原文の一節と出典 URL を確かめられる

## 4. あるとうれしい機能

- キーワードで探す
- 同じ分野について、主体ごとの件数 (実施済み・進行中・予定) を並べて比べる
- 気になる出来事を保存し、メモを付けておく (後で「本当に実施されたか」を確かめるため)
- 絞り込みの条件を覚えておき、次に開いたとき同じ状態から始まる

## 5. 今回は作らないもの

- 資料の収集・本文抽出・出来事の取り出し (今ある DB から書き出した分だけを載せる)
- LLM による質問・回答・解説、ログイン、サーバー
- 国会議員個人の発言 (党の立場として扱わないもの)

## 6. 守ること

- 資料の要約は LLM が作ったもので誤りがありうる。必ず原文の一節と出典を一緒に出し、そのことを画面に書く
- 個人の名前は出さない (会議録の題名にある発言者の氏名は外し、肩書だけ残す。地方選挙の候補者についての党の記事は載せない)。
  ただし大臣・党首など公人の名前が、根拠の原文の引用の中に出ることはある (原文を書き換えないため)
- 政党の扱いに差をつけない (並び順・色の強さは同じ規則で決める)

## 7. 使う場面の想定【AIの案】

**いつ・どこで・何秒くらい**
- 通学・通勤の電車やバス停、昼休み。ニュースや SNS で話題を見た直後に開き、**30秒〜2分** で
  「その件、政府と各党は何をしてきたか」を確かめる。家で腰を据えて 5〜10 分眺めることもある
- 立ったまま、つり革を持って **片手 (親指だけ)** で使うことが多い。だから操作は画面の下半分に寄せる
  (下のタブ、下からせり上がる詳細、下にある「保存」ボタン)。上は見るだけの場所にする

**初めて開いたとき — 困りそうなこと**
- ○◐● などの印や「与党・野党」の意味が分からない → 一覧の先頭に一行の凡例を出し、印には必ず「実施済み」などの文字を添える
- 何をすればいいか分からない → 主体のボタンを横一列に並べ、押せば絞れることを見た目で示す。保存タブには例を3件入れておき、
  「こう使う」が分かるようにする (例は1回の操作で消せる)
- 要約を事実と思い込む → 詳細には原文の一節を目立つ形で出し、「AI が資料から取り出した要約です」と書く

**2回目に開いたとき**
- 前回の絞り込み (主体・分野・タブ) を覚えておき、同じ状態から始める。ただし条件が効いていることが分かるよう、
  件数と「条件を外す」を上に出す
- 前に保存した予定が「時期を過ぎた」かどうかが分かるよう、保存一覧で時期を過ぎた予定に印を付ける

**データが増えたとき**
- 今でも約1,260件ある。一度に全部描かず、50件ずつ出してスクロールで読み足す
- 月ごとに見出しを付け、どのあたりを見ているかを見失わないようにする
- 探す語は入力するそばから絞る。結果の件数を常に出す
- 比べる画面は件数の表にして、件数のマスを押すとその一覧に飛べるようにする (長い一覧を読む前に全体の形が分かる)

## 8. 画面の案【AIの案】

1. **一覧 (タイムライン)**
   - 「これまで / 進行中 / これから」の切り替え、主体のボタン列、分野の選択、キーワード
   - 月ごとの見出しの下に出来事のカード (主体の色の帯、状態の印と文字、題名、時期)。
     「これから」は近い順、時期が書かれていない予定は最後にまとめる
   - カードを押すと、下から詳細がせり上がる: 要約、根拠の原文の一節、出典 (別の資料に同じ出来事があれば最大3件)、保存とメモ
2. **比べる**
   - 分野を1つ選ぶと、主体ごとに「実施済み・進行中・予定」の件数を並べた表を出す。マスを押すとその条件の一覧へ
3. **保存**
   - 保存した出来事とメモの一覧。メモはその場で直せる。保存を外す、例を消す

## 9. 例のデータ【AIの案】

保存タブに最初から入っている3件 (「消費税」と「地域の予算」を追いかけている、という想定)。

| 出来事 | 主体・状態 | メモの例 |
|---|---|---|
| 地域未来戦略実現フレームを策定 | 政府・予定 (2026年末まで) | 年末までに策定するとの答弁。年明けに出たか確かめる |
| 財源確保消費税・支援金法案が衆院を通過 | 自民・実施済み | 参院でどうなったか、次に見る |
| 消費税の期限なし減税と廃止を提言 | 共産・予定 | 与党の法案と並べて比べる |

一覧・比べる画面のデータは、2026-11-23 時点の `data/crawler.db` から書き出した出来事 (議員個人の発言と地方選挙の候補者の記事を除く 1,264 件) をそのまま使う。
